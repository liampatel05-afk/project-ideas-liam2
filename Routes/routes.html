Task Manager – HTTP Route Documentation

This document describes all HTTP routes used by the Task Manager application, including server actions, database interactions, status codes, and responses.

GET /tasks

Method: GET

Purpose: List all tasks, optionally filtered by status.

Data Extraction

  • Optional query parameter: status (e.g. ?status=in-progress)

Database Interactions

-- If no status filter
SELECT id, title, description, deadline, status
FROM tasks
ORDER BY deadline;

-- If status filter provided
SELECT id, title, description, deadline, status
FROM tasks
WHERE status = ?
ORDER BY deadline;

Server Actions

  • Extract optional status query parameter.
  • Execute appropriate SELECT query.
  • Build HTML page listing tasks with filter form.

Response

  • Status code: 200 OK
  • Response type: HTML page
  • Details: Page shows all tasks (optionally filtered) with links to individual task pages.

GET /tasks/:taskId

Method: GET

Purpose: Show details of a single task.

Data Extraction

  • Path parameter: taskId

Database Interactions

SELECT id, title, description, deadline, status
FROM tasks
WHERE id = ?;

Server Actions

  • Extract taskId from URL.
  • Execute SELECT query to fetch task.
  • If not found: prepare 404 response.
  • If found: render HTML page with task details.

Response

  • Status code: 200 OK if found, 404 Not Found if missing.
  • Response type: HTML page.
  • Details: Shows title, description, deadline, status, and links to admin edit page.

GET /admin/tasks

Method: GET

Purpose: Show admin page with create-task form and list of tasks.

Data Extraction

  • No request body; optional query params if needed.

Database Interactions

SELECT id, title, description, deadline, status
FROM tasks
ORDER BY deadline;

Server Actions

  • Fetch existing tasks.
  • Render HTML page with create form and links to edit/delete pages.

Response

  • Status code: 200 OK
  • Response type: HTML page
  • Details: Admin interface for creating tasks and navigating to edit/delete.

GET /admin/tasks/:taskId

Method: GET

Purpose: Show admin page for editing or deleting a specific task.

Data Extraction

  • Path parameter: taskId

Database Interactions

SELECT id, title, description, deadline, status
FROM tasks
WHERE id = ?;

Server Actions

  • Extract taskId from URL.
  • Execute SELECT query.
  • If not found: return 404 Not Found.
  • If found: render form with pre-filled values and delete form.

Response

  • Status code: 200 OK or 404 Not Found.
  • Response type: HTML page.
  • Details: Edit form and delete button for the selected task.

POST /tasks

Method: POST

Purpose: Create a new task.

Data Extraction

  • POST body fields: title, description, deadline, status

Database Interactions

INSERT INTO tasks (title, description, deadline, status)
VALUES (?, ?, ?, ?);

Server Actions

  • Extract fields from POST body.
  • Validate all required fields are present and non-empty.
  • If validation fails: re-render form with errors (400 Bad Request).
  • If validation passes: execute INSERT query.
  • Redirect to task list page.

Response

  • Status code: 303 See Other on success, 400 Bad Request on validation error.
  • Response type: Redirect (on success) or HTML form with errors (on failure).
  • Redirect target: GET /tasks.

POST /tasks/:taskId

Method: POST

Purpose: Update an existing task.

Data Extraction

  • Path parameter: taskId
  • POST body fields: title, description, deadline, status

Database Interactions

UPDATE tasks
SET title = ?, description = ?, deadline = ?, status = ?
WHERE id = ?;

Server Actions

  • Extract taskId and form fields.
  • Validate fields.
  • If validation fails: re-render edit form with errors (400 Bad Request).
  • If validation passes: execute UPDATE query.
  • Redirect to task detail page.

Response

  • Status code: 303 See Other on success, 400 Bad Request on validation error.
  • Response type: Redirect or HTML page with errors.
  • Redirect target: GET /tasks/:taskId.

POST /tasks/:taskId/delete

Method: POST

Purpose: Delete an existing task.

Data Extraction

  • Path parameter: taskId

Database Interactions

DELETE FROM tasks
WHERE id = ?;

Server Actions

  • Extract taskId.
  • Execute DELETE query.
  • Redirect to task list page.

Response

  • Status code: 303 See Other on success.
  • Response type: Redirect.
  • Redirect target: GET /tasks.
