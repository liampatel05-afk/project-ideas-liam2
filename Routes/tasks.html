Task Manager – Task Routes

GET Routes

/tasks

Method: GET

Server Action: SELECT * FROM tasks;

Side Effects: None

Client Response: HTML page listing all tasks

/tasks/:taskId

Method: GET

Server Action: SELECT * FROM tasks WHERE id = :taskId;

Side Effects: None

Client Response: HTML page showing details of one task

/admin/tasks

Method: GET

Server Action: None (loads form)

Side Effects: None

Client Response: HTML page with create-task form

/admin/tasks/:taskId

Method: GET

Server Action: SELECT * FROM tasks WHERE id = :taskId;

Side Effects: None

Client Response: HTML page with edit/delete forms

POST Routes

/tasks

Method: POST

Server Action:

INSERT INTO tasks(title, description, deadline, status)
VALUES (?, ?, ?, ?);

Side Effects: Creates a new task

Client Response: Redirect to /tasks

/tasks/:taskId

Method: POST

Server Action:

UPDATE tasks
SET title=?, description=?, deadline=?, status=?
WHERE id = :taskId;

Side Effects: Updates an existing task

Client Response: Redirect to /tasks/:taskId

/tasks/:taskId/delete

Method: POST

Server Action:

DELETE FROM tasks WHERE id = :taskId;

Side Effects: Deletes the task

Client Response: Redirect to /tasks
