Task Manager – Admin Routes

GET Routes (Admin)

/admin/tasks

Method: GET

Server Action: None (loads admin interface)

Side Effects: None

Client Response: HTML page containing the “Create Task” form and links to edit/delete pages

/admin/tasks/:taskId

Method: GET

Server Action: SELECT * FROM tasks WHERE id = :taskId;

Side Effects: None

Client Response: HTML page containing forms to edit or delete the selected task

POST Routes (Admin)

/admin/tasks

Method: POST

Server Action:

INSERT INTO tasks(title, description, deadline, status)
VALUES (?, ?, ?, ?);

Side Effects: Creates a new task in the database

Client Response: Redirect to /tasks

/admin/tasks/:taskId

Method: POST

Server Action:

UPDATE tasks
SET title=?, description=?, deadline=?, status=?
WHERE id = :taskId;

Side Effects: Updates the selected task

Client Response: Redirect to /tasks/:taskId

/admin/tasks/:taskId/delete

Method: POST

Server Action:

DELETE FROM tasks WHERE id = :taskId;

Side Effects: Deletes the selected task

Client Response: Redirect to /tasks
