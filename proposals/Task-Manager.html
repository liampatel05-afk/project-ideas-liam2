Task Manager Application

Brief Description

The Task Manager is a simple CRUD web application designed to help individuals or small groups organise tasks, track deadlines, and monitor progress. It provides a clean interface for creating, updating, and completing tasks, with optional grouping features for collaborative work.

Detailed Explanation

This application focuses on productivity and organisation. Users can create tasks with titles, descriptions, deadlines, and status indicators. Tasks can be assigned to groups or individuals, allowing flexible use for both personal and collaborative environments.

The system is intentionally lightweight, avoiding complex front-end JavaScript. It is designed around clear HTML interfaces and simple CRUD operations, making it ideal for rapid development and easy demonstration in assignment videos.

Possible Names

  • Task Manager
  • TaskFlow
  • GroupTrack
  • TeamTasks

User Types

  • Standard User: Can create, edit, complete, and delete tasks.
  • Group User: Can view tasks assigned to their group.
  • Administrator (optional): Can manage users and groups.

User Requirements (User Stories)

  • As a user, I want to create tasks so I can track my work.
  • As a user, I want to set deadlines so I do not miss important dates.
  • As a user, I want to mark tasks as completed so I can track progress.
  • As a group member, I want to see tasks assigned to my group.
  • As an admin, I want to manage users and groups.

Database Structure

  • Users — id, name, email
  • Groups — id, group_name
  • Tasks — id, title, description, deadline, status
  • TaskAssignments — id, task_id, user_id or group_id

Challenges

  • Designing a clean and simple user interface.
  • Ensuring tasks can be assigned to either users or groups.
  • Managing CRUD operations without overly complex JavaScript.
  • Keeping the database structure simple but flexible.

Data Requirements

  • User information (name, email)
  • Task details (title, description, deadline, status)
  • Group information (group name)
  • Assignments linking tasks to users or groups
