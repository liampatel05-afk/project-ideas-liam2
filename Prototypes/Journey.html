User Journey – Task Manager Application

This document describes how a typical user interacts with the Task Manager application. It explains each step of the journey and shows the prototype pages using embedded iframes.

1. Viewing All Tasks

The user begins at the main task list page. Here they can browse all tasks, filter them by status, and click on any task to view more details.

2. Viewing a Single Task

After selecting a task, the user is taken to the task detail page. This page shows the description, deadline, status, and assigned users or groups. The user can choose to edit the task from here.

3. Creating a New Task (Admin)

Administrators or users with permission can create new tasks. They navigate to the admin task page, where they fill out a form with the task details and submit it.

4. Editing or Deleting a Task (Admin)

When editing a task, the user sees a form pre-filled with the current task information. They can update the fields or choose to delete the task entirely.

Summary

This journey shows how users move through the Task Manager application: viewing tasks → inspecting details → creating tasks → editing or deleting tasks. These prototype pages represent the core GET routes of the system.
